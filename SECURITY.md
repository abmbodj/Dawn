# Security

Please report suspected vulnerabilities by opening a GitHub issue:

https://github.com/abmbodj/Dawn/issues

Use a clear title such as `Security: <short summary>`. Avoid posting secrets, live credentials,
private tokens, or exploit payloads that would put other users at immediate risk. Include enough
detail for the maintainers to reproduce and assess the issue.

## Supported Version

Security fixes target the current `main` branch and the latest source release.
